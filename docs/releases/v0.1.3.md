# Starsector System Ranker v0.1.3

This release updates the colony plan search and adds progress feedback to the TUI.

## Improvements

- `--solve` and `--maximize` now use evolutionary plan search by default,
  combining colony plans and refining promising candidates within the time budget.
- Plan scoring reuses per-planet economy calculations, and the application uses
  mimalloc to reduce allocation overhead.
- The TUI reports solver phases while a job runs.
- Colony items can be selected for Pareto sweeps.
- Ctrl+C quits the TUI from every screen.

## Fixes

- Plan evaluation batches stop when the solver deadline or cancellation fires.
- Evolutionary search settings reject nonfinite numeric overrides and guard
  against invalid population and search parameters.

## Upgrading

Unpack this release and run the installer again, or run `system_solver install`.

Evolutionary search uses a wall-clock budget, so results can vary between runs
and machines. See `docs/CLI.md` for the search behavior and available options.
